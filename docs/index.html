Nutrislice Unofficial MCP

Nutrislice Unofficial MCP is a hosted Model Context Protocol (MCP) server that provides campus dining locations, daily and weekly menus, ingredients, and published nutrition data to compatible AI assistants. It allows you to access dining information directly through ChatGPT, Claude, or another client that supports remote MCP connections.

Example

"What's for lunch at Northside Café at WSU, Pullman today? Which options have the most protein? Give me a weekly protein focused plan under $15 a day"

Getting started

Add the following server URL to your MCP-compatible client.

https://nutrislice-mcp-unofficial.prmvr.workers.dev/mcp

Transport: Streamable HTTP
Authentication: None

ChatGPT

  1. Open ChatGPT Plugins.
  2. Select Add custom MCP server.
  3. Enter the name nutrislice and paste the URL.
  4. Select no authentication and save the connection.
  5. Enable the plugin in your conversation.

Custom MCP support depends on your ChatGPT plan or workspace. Setup documentation.

Claude

  1. Open Claude.
  2. Go to Customize → Connectors.
  3. Select Add custom connector.
  4. Enter the name nutrislice and paste the URL.
  5. Save and enable the connector.

Setup documentation.

Other MCP clients

Add the server URL as a remote Streamable HTTP connection in any compatible MCP client. No API key is required.

Notes

Available data depends on the dining institution. Menus and nutrition details may change. For food allergies, verify information directly with dining staff.
